# 生日券自动发放插件

## 📋 插件信息

- **插件名称**: 生日券自动发放
- **插件ID**: birthday_coupon
- **版本号**: 1.0.0
- **作者**: lilWAN Team
- **分类**: 优惠促销

## 🎯 功能说明

用户生日当天自动发放生日优惠券，支持：

- ✅ 生日当天自动触发
- ✅ 自定义券模板
- ✅ 自定义有效期
- ✅ 发送生日祝福消息
- ✅ 提前发放设置
- ✅ 发放记录查询
- ✅ 统计分析报表

## 📦 安装说明

### 1. 准备工作

确保系统已启用：
- 用户管理模块
- 订单管理模块
- 优惠券功能

### 2. 打包插件

```bash
cd birthday-coupon-plugin
zip -r birthday-coupon-plugin.zip .
```

### 3. 上传安装

1. 登录管理后台
2. 进入【营销管理】→【营销插件】
3. 点击【上传插件】
4. 选择 `birthday-coupon-plugin.zip`
5. 系统自动安装

### 4. 配置插件

安装后需要配置：

1. **生日券模板ID**: 选择要发放的优惠券模板
2. **自动发放**: 是否自动发放（建议开启）
3. **每天限领次数**: 默认1次
4. **发送祝福消息**: 是否同时发送生日祝福
5. **提前发放天数**: 可提前0-7天发放

### 5. 启用插件

点击【启用】按钮，刷新页面后可看到【生日券管理】菜单。

## 🔧 技术实现

### TCALS模型

#### Trigger（触发）
- 用户生日当天
- 用户注册时（可选）

#### Condition（条件）
- 用户已设置生日信息
- 未命中黑名单
- 未超过每日领取次数

#### Action（动作）
- 发放生日优惠券
- 发送生日祝福消息

#### Limit（限制）
- 每人每天限领1次
- 每人每年限领1次
- 总预算10000元

#### Settlement（结算）
- 优先级：4
- 可叠加：满减、会员折扣
- 不可叠加：秒杀

### 数据表

#### plugin_birthday_coupon_records（发放记录）
- 记录每次发放的券信息
- 记录使用情况
- 关联订单信息

#### plugin_birthday_coupon_statistics（统计数据）
- 按日统计发放数量
- 统计使用率
- 计算GMV贡献

## 📊 使用统计

安装后可在【生日券管理】→【统计分析】查看：

- 总发放数量
- 总使用数量
- 使用率
- GMV贡献
- 发放趋势图
- 用户生日分布
