# 插件接口详解

## MarketingPluginInterface

所有营销插件必须实现 `MarketingPluginInterface` 接口。

### 接口定义

```php
namespace App\Contracts\Marketing;

interface MarketingPluginInterface
{
    public function getCode(): string;
    public function getName(): string;
    public function getSettlementStep(): int;
    public function isApplicable(PricingContext $context): bool;
    public function calculate(PricingContext $context): array;
    public function getPriority(): int;
    public function getStackingRule(): string;
    public function getMutuallyExclusivePlugins(): array;
}
```

---

## 方法详解

### getCode()

返回插件的唯一标识符。

**签名**:
```php
public function getCode(): string
```

**示例**:
```php
public function getCode(): string
{
    return 'my-discount';
}
```

**要求**:
- 必须唯一
- 只能包含字母、数字、下划线、中划线
- 建议使用中划线分隔单词

---

### getName()

返回插件的显示名称。

**签名**:
```php
public function getName(): string
```

**示例**:
```php
public function getName(): string
{
    return '我的折扣插件';
}
```

---

### getSettlementStep()

返回插件在价格计算流程中的步骤（1-7）。

**签名**:
```php
public function getSettlementStep(): int
```

**步骤说明**:

| 步骤 | 说明 | 示例插件 |
|-----|------|---------|
| 1 | 商品原价 | - |
| 2 | 商品级优惠 | 优惠券、第N件折扣 |
| 3 | 订单级优惠 | 满减、满折 |
| 4 | 会员折扣 | VIP折扣 |
| 5 | 运费计算 | 免运费 |
| 6 | 积分抵扣 | 积分换钱 |
| 7 | 支付优惠 | 微信支付优惠 |

**示例**:
```php
public function getSettlementStep(): int
{
    return 2; // 商品级优惠
}
```

---

### isApplicable()

检查插件是否可用于当前订单。

**签名**:
```php
public function isApplicable(PricingContext $context): bool
```

**参数**:
- `$context`: 价格计算上下文对象

**示例**:
```php
public function isApplicable(PricingContext $context): bool
{
    // 1. 检查活动时间
    if (!$this->isWithinTimeRange()) {
        return false;
    }

    // 2. 检查用户条件
    if (!$context->user || $context->user->level !== 'vip') {
        return false;
    }

    // 3. 检查订单金额
    if ($context->currentAmount < 100) {
        return false;
    }

    return true;
}
```

**最佳实践**:
- 按照成本从低到高的顺序进行检查
- 使用早返回（early return）
- 不要在此方法中修改任何状态

---

### calculate()

计算折扣金额。

**签名**:
```php
public function calculate(PricingContext $context): array
```

**返回值**:
```php
[
    'discount_amount' => float,  // 折扣金额（正数）
    'items' => array,            // 受影响的商品项
    'metadata' => array          // 额外信息
]
```

**示例1 - 订单级折扣**:
```php
public function calculate(PricingContext $context): array
{
    // 10%折扣
    $discountAmount = $context->currentAmount * 0.1;

    return [
        'discount_amount' => $discountAmount,
        'items' => [],
        'metadata' => [
            'discount_rate' => 0.1,
        ],
    ];
}
```

**示例2 - 商品级折扣**:
```php
public function calculate(PricingContext $context): array
{
    $discountAmount = 0;
    $affectedItems = [];

    foreach ($context->items as $item) {
        // 只对特定分类商品打折
        if ($item['category_id'] === 1) {
            $itemDiscount = $item['price'] * $item['quantity'] * 0.1;
            $discountAmount += $itemDiscount;
            
            $affectedItems[] = [
                'product_id' => $item['product_id'],
                'discount' => $itemDiscount,
            ];
        }
    }

    return [
        'discount_amount' => $discountAmount,
        'items' => $affectedItems,
        'metadata' => [],
    ];
}
```

**要求**:
- `discount_amount` 必须是非负数
- 不能超过 `$context->currentAmount`
- 必须返回所有3个键

---

### getPriority()

返回插件的优先级（数字越大优先级越高）。

**签名**:
```php
public function getPriority(): int
```

**示例**:
```php
public function getPriority(): int
{
    return 100; // 默认优先级
}
```

**推荐值**:
- 200+: 高优先级（重要促销活动）
- 100: 默认优先级
- 50-: 低优先级（兜底折扣）

---

### getStackingRule()

返回插件的叠加规则。

**签名**:
```php
public function getStackingRule(): string
```

**可选值**:
- `'stack'`: 可叠加（默认）
- `'mutex'`: 互斥（不能与指定插件同时使用）
- `'choose_best'`: 择优（与其他插件比较，选折扣最大的）

**示例**:
```php
public function getStackingRule(): string
{
    return 'stack'; // 可与其他优惠叠加
}
```

---

### getMutuallyExclusivePlugins()

返回与此插件互斥的插件代码列表。

**签名**:
```php
public function getMutuallyExclusivePlugins(): array
```

**示例**:
```php
public function getMutuallyExclusivePlugins(): array
{
    return ['other-coupon', 'full-reduce']; // 与这两个插件互斥
}
```

**注意**: 只在 `getStackingRule()` 返回 `'mutex'` 时生效。

## PricingContext

价格计算上下文对象，包含订单和用户信息。

### 属性

```php
class PricingContext
{
    public Collection $items;          // 购物车商品项
    public ?User $user;                // 用户对象（可能为null）
    public float $currentAmount;       // 当前金额
    public float $originalAmount;      // 原始金额
    public array $appliedPlugins;      // 已应用的插件代码
    public array $discountDetails;     // 折扣明细
    public array $metadata;            // 元数据
    public int $currentStep;           // 当前步骤
}
```

### 方法

#### getUserId()

获取用户ID。

```php
public function getUserId(): ?int
```

示例：
```php
$userId = $context->getUserId();
if ($userId) {
    // 用户已登录
}
```

#### getProductIds()

获取购物车中的商品ID列表。

```php
public function getProductIds(): array
```

示例：
```php
$productIds = $context->getProductIds();
// [1, 2, 3]
```

#### hasAppliedPlugin()

检查是否已应用某个插件。

```php
public function hasAppliedPlugin(string $code): bool
```

示例：
```php
if ($context->hasAppliedPlugin('coupon-10')) {
    // 已经使用了coupon-10插件
}
```

#### getMetadata()

获取元数据。

```php
public function getMetadata(string $key, $default = null)
```

示例：
```php
$province = $context->getMetadata('province', '广东省');
```

## 完整示例

```php
<?php

namespace Plugins\MyDiscount;

use App\Contracts\Marketing\MarketingPluginInterface;
use App\Services\Marketing\PricingContext;

class Plugin implements MarketingPluginInterface
{
    public function getCode(): string
    {
        return 'my-discount';
    }

    public function getName(): string
    {
        return '我的折扣';
    }

    public function getSettlementStep(): int
    {
        return 2;
    }

    public function isApplicable(PricingContext $context): bool
    {
        return $context->currentAmount >= 50;
    }

    public function calculate(PricingContext $context): array
    {
        $discountAmount = $context->currentAmount * 0.1;

        return [
            'discount_amount' => $discountAmount,
            'items' => [],
            'metadata' => ['rate' => 0.1],
        ];
    }

    public function getPriority(): int
    {
        return 100;
    }

    public function getStackingRule(): string
    {
        return 'stack';
    }

    public function getMutuallyExclusivePlugins(): array
    {
        return [];
    }
}
```
