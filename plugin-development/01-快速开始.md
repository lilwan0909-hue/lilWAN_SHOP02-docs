# 快速开始

## 5分钟创建第一个插件

### 1. 生成插件脚手架

使用CLI命令快速生成插件骨架：

```bash
php artisan marketing:make-plugin my-discount \
  --name="我的折扣" \
  --type=discount \
  --step=2
```

**参数说明**:
- `my-discount`: 插件代码（唯一标识符）
- `--name`: 插件显示名称
- `--type`: 插件类型（coupon/discount/gift/points）
- `--step`: 结算步骤（2-7）

**可选参数**:
- `--with-frontend`: 生成前端管理页面
- `--with-migration`: 生成数据库迁移文件

### 2. 编辑插件逻辑

打开生成的插件文件：

```
storage/app/plugins/my-discount/src/Plugin.php
```

实现 `calculate()` 方法：

```php
public function calculate(PricingContext $context): array
{
    // 实现你的折扣逻辑
    $discountAmount = $context->currentAmount * 0.1; // 10%折扣

    return [
        'discount_amount' => $discountAmount,
        'items' => [],
        'metadata' => ['rate' => 0.1],
    ];
}
```

### 3. 配置TCALS规则

编辑 `tcals.json` 文件，配置插件的触发条件、限制等：

```json
{
  "trigger": {
    "type": "checkout"
  },
  "conditions": {
    "logic": "AND",
    "rules": [
      {
        "type": "order_amount",
        "min_amount": 50
      }
    ]
  },
  "action": {
    "type": "discount_percent",
    "value": 10
  },
  "limits": [
    {
      "type": "usage_count",
      "max_count": 10000
    }
  ]
}
```

### 4. 打包插件

```bash
cd storage/app/plugins/my-discount
zip -r my-discount.zip . -x ".DS_Store"
```

### 5. 上传并启用

1. 登录管理后台
2. 导航到：营销管理 -> 插件管理
3. 点击"上传插件"
4. 选择 `my-discount.zip` 文件
5. 上传成功后，点击"启用"

### 6. 测试

创建订单进行测试：
- 订单金额 < 50元：不享受折扣
- 订单金额 ≥ 50元：自动享受10%折扣

## 常见问题

### Q1: 插件上传后没有显示？

检查以下几点：
- plugin.json 文件格式是否正确
- 插件代码是否唯一
- 是否有语法错误

### Q2: 插件不生效？

检查以下几点：
- 插件是否已启用
- TCALS条件是否满足
- 检查日志：`storage/logs/laravel.log`

### Q3: 如何调试插件？

在插件代码中添加日志：

```php
use Illuminate\Support\Facades\Log;

Log::info('Plugin executed', [
    'current_amount' => $context->currentAmount,
    'discount' => $discountAmount,
]);
```

查看日志：`storage/logs/laravel.log`
